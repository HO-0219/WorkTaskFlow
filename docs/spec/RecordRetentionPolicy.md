# 업무 기록 보존 정책

## 종료된 업무

- 완료, 반려, 취소된 업무의 제목, 설명, 담당자, 마감일과 체크리스트는 수정하거나 삭제할 수 없다.
- 업무 삭제 API는 제공하지 않는다.
- 완료 업무만 재개할 수 있으며 팀 그룹에서는 팀장 권한과 재개 사유가 필요하다.
- 재개는 기존 완료 이력을 변경하지 않고 `완료 → 진행 중` 상태 이력을 새로 추가한다.
- 반려·취소 기록은 재개하지 않고 새 업무로 등록한다.

## 댓글과 후속 기록

- 진행 중 업무의 댓글은 작성자가 작성 후 15분 동안만 수정하거나 소프트 삭제할 수 있다.
- 댓글 수정 전·후 내용과 수정자는 `comment_revisions`에 별도 보존한다.
- 삭제된 댓글은 행을 제거하지 않고 삭제 시각과 원문을 DB에 유지하며 화면에는 삭제 표시만 제공한다.
- 종료된 업무의 기존 댓글은 수정·삭제할 수 없다.
- 종료 후에도 회고나 정정 사항은 새로운 후속 기록으로 추가할 수 있으며 해당 기록 역시 잠긴다.
- 완료 업무가 재개되어도 완료 이전 및 완료 상태에서 작성된 댓글은 계속 잠긴 상태로 유지한다.

## 상태 및 감사 이력

- 업무 상태 이력은 수정·삭제 API를 제공하지 않는다.
- 상태 변경자, 이전·다음 상태, 사유와 변경 시각을 보존한다.
- 완료 업무 재개에는 사유를 필수로 기록한다.
