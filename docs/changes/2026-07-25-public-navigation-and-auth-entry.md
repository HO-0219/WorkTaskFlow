- 개인정보 영향: 직접적인 신규 수집 없음

- DB 마이그레이션: 없음

## 환경별 변경

| 단계 | 환경 변수 | 외부 콘솔 | QA |
| --- | --- | --- | --- |
| 1 로컬 | `VITE_CONTACT_EMAIL` | Google OAuth는 disabled 가능 | 무료 시작→로그인, 데모 종료, 다국어 공개 페이지 |
| 2 ngrok | 같은 문의 주소 | Google Redirect URI를 ngrok 주소로 추가 | 외부 Google 로그인, 모바일 메뉴 |
| 3 AWS QA | QA 문의 주소 | QA OAuth 앱과 Redirect URI | 공개 페이지는 유지하되 전체 검색 차단 |
| 4 도메인 사전 | 실제 담당 문의 주소 | 실제 도메인 Redirect URI | 공개 콘텐츠·가격 문구·문의 수신 검토 |
| 5 운영 | 운영 문의 주소 | 검수 완료 운영 OAuth 앱 | 검색 노출, 고객지원 응답, 운영 약관 일치 |

## 보안·개인정보

- 공용 데모 진입 시 `sessionMode=demo`를 표시한다.
- 데모에서 로그인 페이지로 이동하면 데모 refresh cookie와 access token을 정리한다.
- 앱 내에 `읽기 전용 데모`와 `데모 종료·로그인`을 표시한다.
- Google OAuth 신규 가입 동의 흐름이 완성되기 전에는 공급자 설정을 활성화하지 않는다.

## 배포 검증

- `/product`, `/b2b`, `/pricing`, `/contact` 한국어·영어 전환
- 미정 상태인 개발자 페이지는 공개 메뉴와 검색 사이트맵에서 제외
- 랜딩의 모든 `무료로 시작` 링크가 `/login`으로 이동
- 명시적인 데모 버튼만 `/api/v1/auth/demo-session` 호출
- QA 빌드 `robots.txt` 전체 차단
- 운영 승인 빌드 sitemap에 신규 공개 경로 포함
