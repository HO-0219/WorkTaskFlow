## 공통

- [ ] 변경 범위와 DB 마이그레이션을 검토했다.
- [ ] 프런트 프로덕션 빌드가 성공했다.
- [ ] 백엔드 전체 테스트가 성공했다.
- [ ] 비밀값 검사에서 노출이 없다.
- [ ] 신규·변경 환경 변수를 대상 환경에 반영했다.
- [ ] 데이터 백업과 롤백 명령을 확인했다.
- [ ] 개인정보·권한·결제·로그 영향도를 검토했다.
- [ ] `robots.txt`와 검색 노출 정책이 대상 단계와 일치한다.
- [ ] 장애 시 담당자와 중단 기준이 정해졌다.

## 외부 연동

- [ ] 메일 발신자와 테스트 수신자를 확인했다.
- [ ] OAuth Redirect URI와 허용 origin을 확인했다.
- [ ] Toss test/live mode와 키 종류를 교차 확인했다.
- [ ] 재전송·중복 요청·타임아웃을 검증했다.
- [ ] 외부 공급자 실패가 전체 트랜잭션을 잘못 롤백하지 않는다.

## 데이터

- [ ] 대상 DB 이름과 host가 이전 단계/운영과 분리됐다.
- [ ] Flyway가 순서대로 적용된다.
- [ ] 업로드 파일이 재배포 후 유지된다.
- [ ] 백업에서 별도 환경으로 복원해 보았다.
- [ ] 로그에 개인정보·토큰·결제 비밀이 없다.

## 5단계 추가 승인

- [ ] 사업자등록 및 필요한 통신판매업 신고가 완료됐다.
- [ ] 사이트 사업자·고객지원·신고 정보가 정확하다.
- [ ] 개인정보 처리방침·약관·환불정책이 확정됐다.
- [ ] 운영 결제키와 운영 암호화 키가 신규 발급됐다.
- [ ] `TOSS_TEST_MODE=false` 변경을 두 명 이상이 확인했다.
- [ ] `VITE_ALLOW_INDEXING=true`와 canonical 도메인을 확인했다.
