# 5단계: 사업자·통신판매업 등록 완료 실제 운영

마지막 법령 확인일: 2026-07-25  
주의: 아래 내용은 운영 체크리스트이며 세무·법률 자문을 대체하지 않는다.

## 행정 준비

- 사업자등록 완료 후 상호, 대표자, 사업장 주소, 업태·종목, 사업자등록번호 확인
- 온라인 유료 판매에 필요한 통신판매업 신고 대상 여부를 관할 기관에 확인하고, 대상이면 신고 완료
- 결제대행사 운영 상점 심사·정산계좌·운영키 발급 완료
- 고객지원·개인정보 문의가 실제로 접수되는 전화번호와 이메일 준비

통신판매업 신고는 주된 사무소 소재지 관할 기관에 하는 신고이며, 정부24에서 민원 안내와 신청 경로를 제공한다. 신고 면제 가능성이 있더라도 자체 판단으로 생략하지 말고 최신 시행령과 관할 기관에 확인한다.

## 사이트에 표시할 정보

- 상호 및 대표자명
- 사업장 주소와 고객지원 연락처
- 사업자등록번호
- 통신판매업 신고번호와 신고기관 확인 정보
- 개인정보 처리방침, 이용약관, 유료서비스·청약철회·환불정책
- 상품 또는 구독의 가격, 결제 방법, 공급 시기와 계약 해지 방법

표시값은 코드에 직접 넣지 않고 운영 환경값 또는 관리 가능한 설정으로 주입한다. 변경 시 사이트, PG사, 세무 정보와 통신판매업 변경신고 필요 여부를 함께 확인한다.

## 운영 전 환경 전환

| 항목 | 실제 운영 값 |
| --- | --- |
| `FRONTEND_URL` | 운영 HTTPS origin |
| `VITE_PUBLIC_SITE_URL` | 운영 HTTPS origin |
| `AUTH_SECURE_COOKIE` | `true` |
| DB | 운영 전용 암호화 RDS/MySQL, TLS, 자동 백업 |
| 업로드 | 운영 전용 암호화 저장소와 백업 |
| SMTP/OAuth | 운영 전용 계정과 검수 완료 설정 |
| Toss | 신규 운영 client/secret key |
| `PAYMENT_ENCRYPTION_KEY_BASE64` | 운영 전용 신규 32바이트 키, 복구 가능하게 보관 |
| `TOSS_TEST_MODE` | 운영 전환 승인 시에만 `false` |
| `DEMO_ENABLED` | 정책에 따라 읽기 전용 유지 또는 `false` |
| `VITE_ALLOW_INDEXING` | 출시 승인 후 `true` |
| Search Console | 운영 속성 검증 후 `sitemap.xml` 제출 |

결제 암호화 키를 분실하거나 임의로 교체하면 기존 저장 billing key를 복호화할 수 없다. 키 교체는 데이터 재암호화·결제수단 재등록·복구 계획과 함께 수행한다.

## 출시 승인 게이트

- 운영키가 로그·Git·프런트 번들에 없는지 검사
- 운영 결제 최소 금액 승인·취소·환불·중복 요청 확인
- 가입 동의 버전과 공개 약관 버전 일치
- 사업자·통신판매 정보와 고객지원 연락처 표시 확인
- DB와 업로드 복원 리허설 완료
- 취약점·권한·개인정보·로그 보존 검토 완료
- 장애 알림 당직자와 롤백 담당자 지정
- 개인정보 열람·정정·삭제·동의 철회 요청 처리 연습

## 운영 중 반복 업무

- 매 배포: 3단계 AWS QA → 4단계 사전 서비스 → 운영 승인
- 매월: IAM·보안 그룹·비밀 접근·관리자 계정 검토
- 분기: 복원 훈련, 결제 재전송/중복 방지, 개인정보 파기 확인
- 변경 즉시: 상호·대표자·주소·도메인·연락처·수탁사·가격·환불정책 문서 반영
- 법령 및 공급자 정책은 정기 재확인하고 문서의 `마지막 확인일` 갱신
